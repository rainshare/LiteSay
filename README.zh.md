# LiteSay

[English](README.md) | 中文

**轻译 · 轻松读懂每一页。**

LiteSay 是一款基于 Manifest V3 的网页翻译扩展，支持整页、划词和单段悬停翻译，提供多种翻译服务与自定义 API 接入，并保留网页原文供对照阅读。

## 主要功能

- **整页翻译**：翻译正文，并持续处理动态加载的内容；支持一键还原。
- **划词与悬停**：翻译选中文字或当前段落。
- **双语阅读**：保留原文对照，支持仅译文显示。
- **多种服务**：选择内置翻译服务，或通过自定义 API 接入兼容的远端和本机服务。
- **网站适配**：针对不同网站优化翻译范围和显示效果，支持自定义站点规则。

## 安装

适配 Chrome、Firefox 及其他 Chromium 浏览器。

### Chrome 等 Chromium 浏览器

1. 下载仓库源码并解压。
2. 打开浏览器的扩展管理页面：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `src/` 目录。
5. 刷新已打开的网页。

### Firefox

Firefox 使用专用扩展包，不能直接加载上述 `src/` 目录。

1. 准备 Firefox 专用扩展包（ZIP），或将其解压到本地目录。
2. 在 Firefox 中打开 `about:debugging#/runtime/this-firefox`。
3. 点击“临时载入附加组件”，选择 ZIP 包；若已解压，选择扩展目录中的 `manifest.json`。
4. 刷新已打开的网页。

临时加载的扩展会在 Firefox 重启后卸载，需要重新载入。参见 [Mozilla 临时安装说明](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)。

源码目录和扩展包已包含运行所需资源，安装时无需 Node.js 或额外构建。请保留本地扩展文件；更新后，重新加载扩展并刷新网页。

## 使用

| 翻译方式 | 默认操作                                                           |
| -------- | ------------------------------------------------------------------ |
| 整页翻译 | 按 **Alt+A**，或点击网页悬浮按钮、浏览器工具栏图标；再次触发可还原 |
| 划词翻译 | 选中文字后点击出现的小圆点，打开译文卡片                           |
| 单段悬停 | 在设置中开启后，按住 **Ctrl** 并悬停在段落上；再次触发可还原       |

在悬浮面板中选择源语言、目标语言、翻译服务和显示方式。划词与悬停的触发方式可在设置中调整。划词卡片支持复制译文、失败重试、Escape 和点击外部关闭。

默认源语言为自动检测，目标语言为简体中文；翻译服务可在面板中选择。目标语言为中文时，会跳过已有中文内容。

整页翻译默认关闭。开启后，扩展会记住开关状态，在新打开或刷新的可用网页中继续自动翻译，并将待翻译内容发送给所选服务；再次触发整页翻译可关闭并还原。

### 翻译服务

可用服务、模型与协议以设置页中的当前选项为准。

- **免费网页翻译**：内置谷歌和微软网页翻译接口，无需填写 API Key。
- **模型服务**：按所选服务要求配置模型和 API Key，费用与额度由服务提供方决定。
- **自定义 API**：按设置页提供的协议配置接口地址、模型和密钥，接入兼容的远端或本机服务。

模型服务配置保存后，可使用设置页中的服务测试确认连通性。Token 用量优先采用服务返回的数据，缺失时使用本地分词器估算，并标明来源；缓存命中不重复计数。

### 网站规则

可用的网站适配及翻译范围以设置页中的站点规则为准。

在设置页中开启或关闭站点规则、调整可选范围，或使用域名和 CSS 选择器添加自定义规则。修改后点击“保存规则”使其生效。

已保存的自定义规则优先于内置规则。更新后如需使用最新内置规则，可选择“恢复默认规则”。未适配的网站使用通用正文识别。

## 隐私与数据安全

使用免费网页翻译或第三方 LLM 接口时，服务商可能保留提交内容和译文，并按其政策用于服务改进或 AI 模型训练。具体以所选服务商的隐私政策、服务条款及账户设置为准，处理敏感内容前请先确认。

- 设置、服务配置和用量保存在当前浏览器中，不提供云同步。
- API Key 在本机加密保存，并在请求时用于接口鉴权。
- 译文缓存以明文保存在本地，有效期为 7 天，最多 1500 条，可在设置页清除。

## 已知限制

- 不处理表单输入、代码、编辑器、隐藏内容和禁止翻译区域。
- 不提供 PDF、图片文字识别或通用 iframe 翻译。
- 浏览器内部页和扩展商店等受限制页面无法使用网页翻译。
- 免费网页翻译接口可能限流，或因网络及服务策略变化暂时不可用。
- 网站结构变化可能影响正文识别和适配规则。

如未出现悬浮按钮，先重新加载扩展并刷新网页。请求失败时，检查网络、服务地址、协议、模型名及可用额度；本机服务需保持运行。

## 源码结构

扩展源码位于 `src/`，运行入口为 [src/manifest.json](src/manifest.json)。

```text
src/
├── _locales/         # 浏览器侧扩展名称与描述
├── api/              # 翻译协议与请求调度
├── app/              # 扩展任务与页面控制
├── assets/           # 图标资源
├── components/       # 共享界面组件
├── config/           # 公开默认配置
├── i18n/             # 界面语言资源
├── platform/         # 浏览器接入
├── plugins/          # 翻译功能与网站适配
├── store/            # 本地设置、密钥、缓存和用量
├── utils/            # DOM 工具与分词器
├── views/            # 设置页与翻译浮层
├── LICENSE           # 随扩展包一起分发的 MIT 许可
└── manifest.json     # 扩展入口和权限声明
```
