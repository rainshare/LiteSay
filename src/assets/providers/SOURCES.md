# Brand icon sources

- `microsoft.svg`: downloaded from [SVG Repo · Microsoft](https://www.svgrepo.com/svg/452062/microsoft), which marks the asset as [CC0](https://www.svgrepo.com/page/licensing/#CC0). The original four rectangles and colors are kept; only the fixed dimensions were removed and the `viewBox` padding tightened to fit the extension's 24px icon box.
- The other vendor assets reuse LobeHub icons; the MIT license is in `LICENSE.txt` in this directory.
- `gemini.svg`: downloaded from [LobeHub Gemini color SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/gemini-color.svg), covered by the same MIT license in this directory.
